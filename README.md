## Labs and project

- **Lab 1: engagement prediction.** For each LinkedIn post, predict whether it did below, typical or above its own author's usual. Scored on macro-F1, with QWK and accuracy reported beside it.
  - Dataset: the Kairos Dataset at [kairos-labs.ai](https://kairos-labs.ai/). Request the archive password on the dataset page. The core archive is about 50 GB; the video archive adds about 100 GB.
  - Baseline and submission repository: [Danil482/kairos-dataset](https://github.com/Danil482/kairos-dataset).
- **Lab 2: multi-source prediction.** A harder task fusing text, images and behaviour, such as demographics, personality or virality.
- **Mini-project.** Teams of 2–3 build a mini start-up: a social-media or AI app with a strong use case, using course methods.
